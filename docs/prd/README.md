# Product Requirements Documents (PRDs)

PRDs define goals, user flows, edge cases, and technical constraints for major product areas.

| PRD | Scope | Key flows |
|-----|--------|-----------|
| [share-trails.md](share-trails.md) | Extension + site | Export/import branches (JSON + public share links); placement & merge |
| [polar-billing.md](polar-billing.md) | Billing | Polar billing integration, subscription management |
| [user-flow-redesign.md](user-flow-redesign.md) | UX | User flow redesign across the product |

Each PRD includes:
- **Goals & success**
- **User flows** (step-by-step)
- **Edge cases & handling** (table)
- **Technical constraints**
- **Out of scope** (current)
